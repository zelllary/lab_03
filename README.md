# Лабораторная работа №3

## Каталог трамвайных маршрутов

### Описание проекта

В лабораторной работе разработан Python-пакет `tram_catalog` для хранения трамвайных маршрутов.

Предметная область — транспортные маршруты. Номер в списке — 20. В списке пять предметных областей, поэтому номер варианта: `(20 - 1) % 5 + 1 = 5`.

Каталог позволяет добавлять, получать, удалять и искать маршруты, а также сохранять данные в JSON-файл и загружать их обратно.

### Требования и установка

Для работы необходимы Python версии 3.14 или выше и менеджер пакетов uv.

Для разработки используются:

- `pytest` — запуск тестов;
- `ruff` — проверка кода;
- `mypy` — проверка типов.

Установка зависимостей из корневой папки проекта:

```powershell
py -3.14 -m uv sync
```

Команда создаёт виртуальное окружение `.venv` и устанавливает зависимости проекта.

### Данные маршрута

Маршрут представлен классом `TramRoute`.

| Поле | Тип | Описание |
| --- | --- | --- |
| `route_id` | `str` | Уникальный идентификатор |
| `name` | `str` | Номер маршрута с возможными буквами |
| `category` | `str` | Территория обслуживания |
| `open_date` | `date` | Дата открытия маршрута |
| `active` | `bool` | Действует ли маршрут |
| `operating_mode` | `str` | Режим работы |

При создании маршрута проверяются следующие правила:

- Идентификатор начинается с `route-`, далее идут минимум три цифры. Например, `route-000`.
- Название начинается с положительного целого числа без ведущих нулей. После числа можно указать до трёх русских букв. Например, `15`, `6Б`, `115Аб`.
- Категория — `городской` или `пригородный`.
- Дата открытия не может быть в будущем.
- Активность задаётся значением `True` или `False`.
- Режим работы — `дневной`, `ночной` или `круглосуточный`.

Идентификатор задаётся вручную. После удаления маршрута его идентификатор можно использовать повторно.

### Возможности каталога

| Метод или операция | Назначение |
| --- | --- |
| `add(item)` | Добавление маршрута |
| `get(item_id)` | Получение маршрута по идентификатору |
| `remove(item_id)` | Удаление маршрута |
| `find_by_category(category)` | Поиск по категории |
| `find_by_name(query)` | Поиск по части названия без учёта регистра |
| `len(catalog)` | Количество маршрутов |
| `for route in catalog` | Перебор маршрутов |
| `item_id in catalog` | Проверка наличия идентификатора |
| `read_only_view()` | Получение неизменяемого кортежа маршрутов |

Маршруты перебираются в порядке добавления. Результаты поиска также сохраняют этот порядок.

Методы поиска возвращают новые списки. Изменение такого списка не меняет каталог.

### Принятые решения

Один маршрут — это объект `TramRoute`. Для него используется
`dataclass`, чтобы не писать вручную инициализацию и сравнение объектов.
Поля проверяются при создании в `__post_init__()`.

Маршруты неизменяемые: в декораторе указан `frozen=True`.
Это также защищает индекс категорий: категория уже добавленного
маршрута не может измениться отдельно от индекса.

Идентификатор и номер маршрута — разные поля. Например, два маршрута
могут называться `15А`, но их идентификаторы должны различаться.
Идентификаторы задаются вручную, удалённые можно использовать снова.

Основной словарь хранит маршруты по идентификаторам. Дополнительный
словарь группирует их по категориям. При удалении маршрут убирается
из обоих словарей.

Перебор выполняется в порядке добавления. Поиск по названию ищет
подстроку: запрос `5а` найдёт `15А` и `115Аб`.

Из дополнительных заданий реализованы индекс по категории
и `read_only_view()`, возвращающий неизменяемый кортеж маршрутов.

### Хранение в JSON

Для сохранения используется функция `save_catalog()`, для загрузки — `load_catalog()`.

Пример содержимого файла:

```json
{
    "format_version": 1,
    "items": [
        {
            "route_id": "route-000",
            "name": "15А",
            "category": "городской",
            "open_date": "2026-11-03",
            "active": true,
            "operating_mode": "дневной"
        }
    ]
}
```

Поле `format_version` обозначает версию структуры файла. Добавление или удаление маршрутов не меняет эту версию.

Дата сохраняется строкой в формате `ГГГГ-ММ-ДД`.

Загрузка создаёт новый каталог. Если файл повреждён, существующий каталог остаётся прежним.

### Обработка ошибок

Все ошибки каталога наследуются от `CatalogError`.

| Исключение | Причина |
| --- | --- |
| `InvalidRouteError` | Некорректные данные маршрута или посторонний объект |
| `DuplicateIDError` | Идентификатор уже есть в каталоге |
| `NotFoundError` | Маршрут с указанным идентификатором отсутствует |
| `UnsupportedFormatError` | Неподдерживаемая версия JSON-файла |
| `DamagedFileError` | Повреждённый JSON или неправильные данные в нём |

### Пример использования

```python
from datetime import date

from tram_catalog.catalog import TramCatalog
from tram_catalog.models import TramRoute
from tram_catalog.storage import load_catalog, save_catalog

catalog = TramCatalog()

route = TramRoute(
    'route-000',
    '15А',
    'городской',
    date(2026, 11, 3),
    True,
    'дневной'
)

catalog.add(route)

print(len(catalog))
print(catalog.get('route-000').name)
print(catalog.find_by_name('а') == [route])

save_catalog(catalog, 'output.json')
loaded_catalog = load_catalog('output.json')

print(list(loaded_catalog) == list(catalog))
```

Ожидаемый вывод:

```text
1
15А
True
True
```

### Тестирование

В папке `tests` находятся тесты модели, каталога, JSON-хранения
и дополнительных возможностей.

Тесты проверяют:

- создание допустимых и недопустимых маршрутов;
- добавление, получение и удаление;
- запрет повторяющихся идентификаторов;
- поиск по категории и части названия;
- порядок перебора;
- сохранение и загрузку JSON;
- обработку повреждённых файлов и неизвестной версии;
- сохранение существующего каталога при ошибке загрузки;
- независимость кортежа для чтения от изменений каталога;
- обновление индекса категорий.

Команды проверки из корневой папки проекта:

```powershell
py -3.14 -m uv run pytest
py -3.14 -m uv run ruff check .
py -3.14 -m uv run mypy src tests
```

### Запуск пакета

Из корневой папки проекта:

```powershell
py -3.14 -m uv run python -m src.tram_catalog
```

При активированном виртуальном окружении:

```powershell
python -m src.tram_catalog
```

При запуске выполняется демонстрация: создание и добавление маршрутов,
поиск, удаление, получение кортежа для чтения, сохранение и загрузка JSON.
Файл `output.json` создаётся в текущей папке и перезаписывается
при повторном запуске.
